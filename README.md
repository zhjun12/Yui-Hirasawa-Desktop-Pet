# 放课后 · 平泽唯桌宠 0.7.1 测试版

Windows 透明桌宠：本地音乐、网易云联动、摸头喂食、番茄钟和学习提醒。

## 启动

完整解压 `平泽唯桌宠-测试版0.7.1.zip`，双击 `YuiCompanion.exe`，不要只移动 exe。当前项目可双击 `启动桌宠.bat`。

点击头部摸头、点击身体打开面板；拖动移动，滚轮缩放，右键打开菜单。关闭面板不退出桌宠；托盘或右键菜单可以退出、找回角色。程序不会自动加入开机启动。

## 贴边隐藏

主动拖动角色，在当前屏幕可用区域的上、下、左、右边缘附近（20 像素内）松开，即可平滑收起，只留下 108×30 像素的轻音标志，外围留 4 像素点击边距。角落按距离最近的边缘收起，距离相同时优先左右边缘。普通点击、缩放和动作变化不触发隐藏。

点击标签可展开；从标签向屏幕内拖动可恢复并继续移动，松开后不触发摸头，也不会立刻再次收起。沿边缘拖动标签可调整其位置。角色和标签随「始终置顶」设置变化。

隐藏期间暂停角色动画渲染和气泡，音乐、网易云联动与番茄钟继续运行；计时结束仍通过托盘通知、控制面板文字及已开启的提示音提醒，不强制展开。系统通知能否显示取决于 Windows 通知设置。

「陪伴 → 拖到屏幕边缘时隐藏」默认开启，关闭后立即展开。托盘或右键菜单「显示桌宠」可展开，「找回桌宠」可移动到主屏幕。隐藏状态不保存，重启后角色正常显示。显示器或可用区域变化时，会将角色或标签放回可见范围。

## 本地唱片架

在「音乐 → 本地唱片架」添加歌曲或文件夹。后台扫描包含子文件夹，支持取消，保留已发现结果；局部读取失败不会丢弃全部结果。

完成后显示新增、重复、跳过及失败数量。新增歌曲进入列表并自动定位，旧搜索过滤会清空，避免新内容被隐藏。「导入详情」可以查看错误原因。

双击歌曲播放，支持搜索、播放/暂停、上下首、进度、音量及循环。「移除选中」不删除原文件。「重新定位文件」可以修复移动后的路径。

支持选择 MP3、WAV、FLAC、OGG、M4A、AAC、WMA。发现文件不等于已验证解码，损坏文件在播放时提示。网易云 `.ncm` 等加密文件无法直接播放，不提供解密。

## 网易云联动

1. 在网易云设置开启「系统媒体控制 / SMTC」，完全退出后重启并播放。
2. 在桌宠「音乐 → 网易云联动」选择网易云会话，可读取真实曲名、歌手和播放状态，使用客户端支持的播放控制。
3. 勾选「允许分析系统声音」，角色随实际声音强弱和起音调整动作。

本机网易云 3.1.41.205529 已验证播放/暂停。客户端公布了上下首能力，但当前未提供播放时间线，进度条禁用，不显示假进度。

没有 SMTC 但存在受支持窗口时，可提供明确标注的定向窗口兼容控制。窗口标题不代表播放状态，兼容模式不伪造状态。不向其他播放器发送全局媒体键。

歌曲/歌单链接仍在网易云网页或客户端打开，不读取完整歌单、不接管账号、不下载音源或安装网易云插件。

## 动作与声音

自动模式跟随音乐页当前选定的来源。切换来源不会自动停止另一个播放器。固定模式保持动作种类，摸头/喂食结束后恢复。托腮和固定大回旋在音乐驱动开启时随播放状态收住；关闭驱动时按普通演示循环。打滚、举手及喂玉米按素材自身节奏播放，不随音乐暂停冻结。安静模式减少随机动作、气泡并暂停系统声音分析。

自动动作从进入情景时重新计时，不再每 18 秒机械轮换：

- 日常待机 30～60 秒后，按权重和冷却选择一次发呆、打滚或举手；尽量避免连续重复。
- 听歌以托腮为主，每次等待 45～90 秒后，从大回旋、趴地打滚、举手伸展中随机选择一个动作；三者基础权重相同，同时遵守冷却和避免连续重复的规则。大回旋每次 3～6 个完整循环，约 2.1～4.2 秒；自动大回旋使用原片速度，以保证循环结束后切换。
- 打滚每次 1～2 个循环；举手每次 2～3 个循环；发呆持续 4～8 秒。大回旋结束后至少冷却 60 秒，打滚、举手冷却 90 秒。
- 摸头和喂食立即响应，临时互动结束后重新判断当前情景并重新等待，不补播过期的小动作。手动固定动作不会被随机替换。
- 播放持续 1 秒、停止持续 1.2 秒后再切换自动情景，减少切歌时的闪动；自动短动作尽量完成当前一个循环后响应情景变化。
- 专注期间保持待机或托腮，不触发随机大动作；贴边隐藏后暂停自动调度，恢复时重新等待。

原视频小动作：在「陪伴」可固定选择，也可点击按钮临时播放。打滚改用用户新视频开头约 1.33 秒的循环（32 帧，约 23.976 fps），按用户圈出的轮廓保留头部及原片可见的躯干、手、腿脚，保留透视与遮挡。举手采用约 2:29.10～2:30.93 的浅蓝衣服片段（55 帧 / 约 1.83 秒），保留头顶完整的半身构图；按统一衣服下摆锚点、统一画布和安全边距处理。星星眼已移除。素材保留原片重复绘制帧，不补画原片未显示的身体。

## 添加动作包

将合格的动作文件夹放到 EXE 旁的 `actions/动作ID/`，在「陪伴」点击「重新载入动作包」。名称、互动按钮、固定模式、帧时长、自动权重及冷却都会从 `motion.json` 读取，无需改代码、重打包或重启音乐。坏包会跳过并显示原因，坏的外置覆盖包会退回内置素材。

素材制作使用项目 `action_pipeline.py`；统一输出透明帧、代表帧、循环预览和检查报告，支持安全替换与回滚。完整范式见项目 `ACTION_WORKFLOW.md` 或包内 `动作导入规范.md`，任务模板见项目 `action-jobs/template.json`。外置个人动作包不会被打进通用发布包。

在「陪伴」选择「呆唯 · 手臂大回旋」。此动作替换旧拨弦动画，直接使用用户提供视频 1:11–1:12 内的一段完整循环，保留原动作的吉他道具，按半身构图去除教室背景。循环为 21 个视频帧 / 0.7 秒，原片包含重复绘制帧，不宣称为 21 张新手绘图。启用音乐驱动时播放速度轻微响应声音强弱，暂停后平缓收住；关闭驱动可独立循环演示。旧 `guitar` 固定设置自动迁移到新动作。

托腮听歌仍使用稳定姿势上的连续局部变形，不是 Live2D。待机表情保留原分帧。「喂玉米」替换吃蛋糕，使用用户提供 GIF 的 4 个原始帧，每帧 80 毫秒，去除背景并保留半身构图。点击后从首帧开始，循环约 4.4 秒后恢复之前的动作；不受音乐暂停影响。旧 `eat` 固定模式直接显示新素材。暂无独立演出服、完整喝茶/打哈欠/挥手及配音。

本地播放分析自身解码音频；网易云在用户开启后分析系统输出回环。**系统声音包含其他应用，当前不是网易云进程专属捕获。**仅在内存处理，不录制文件、不上传、不使用麦克风。声音强弱和起音响应不等于精准节拍同步。

## 学习与设置

默认专注 25 分钟、休息 5 分钟，可修改、暂停、继续及结束。每阶段完成后由用户手动开始下一阶段。音乐与互动不重置计时；专注时减少普通气泡，不停止音乐或改写固定动作。

普通学习提醒默认关闭；番茄钟运行及暂停期间暂缓。必要计时提醒优先于普通气泡。重启恢复设置，不续跑计时；退出后不提醒，不唤醒休眠电脑。声音和系统通知受 Windows 设置影响。

数据保存在程序旁 `data/settings.json`，原音乐留在原位置。更新前备份该文件。交付包不包含用户设置或诊断输出。

验证范围见 `验证结果.md` / 项目 `VALIDATION.md`；参考方案见项目 `REFERENCE_NOTES.md`；素材来源见 `_internal/assets/SOURCES.md`。

## 开发检查

源码运行需要 Windows 和 Python 3.12。在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

生成 Windows 程序可执行 `.\build.ps1`；只构建并自检、不更新本地安装则使用 `.\build.ps1 -BuildOnly`。动作导入规则见 [ACTION_WORKFLOW.md](ACTION_WORKFLOW.md)。现有动作帧随源码提供，无需原始视频即可运行；重做素材需要自行提供对应原片。

仓库排除个人设置、歌曲列表、原始视频、本地音乐、虚拟环境、构建目录及诊断输出。动画截图衍生素材和标志的来源见 [assets/SOURCES.md](assets/SOURCES.md)，相关权利归原权利人所有。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tools\smoke_test.py
.\.venv\Scripts\python.exe tools\v02_integration.py
```

检查使用独立测试设置。真实媒体及回环检查需在实际用户桌面运行。项目 `output/motion-demo.mp4` 是动作原型演示，不是实时跟拍录像。
