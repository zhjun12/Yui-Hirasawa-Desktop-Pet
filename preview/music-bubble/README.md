# 气泡歌词前端预览

双击 `index.html` 打开。保持 `frames/` 和 `pet-timings.js` 与页面放在一起。

布局以普通桌宠为主体：角色下方显示 13px 的 MV 宋体字幕，无边框、无底板；歌词采用预览背景同色的浅米绿色（#edf0e6），配轻微阴影。头顶贴近人物显示「正在听歌」，两侧只有镜像对称、同步跳动的声波，不加音符，暂停时停止特效。上一首、播放/暂停和下一首位于角色左侧，竖向排列；奶油黄、浅粉与浅绿色的半透明圆形气泡有柔和高光，普通键约 34×34px，播放键约 37×37px，不使用独立播放器大窗口。

气泡缓慢上下漂浮，鼠标移入控制区域、键盘聚焦或按住拖动时，暂停漂浮，移开后从原位置继续。只有控制气泡静止，角色动画和歌词照常进行。

拖动角色或歌词可移动整体；三个控制气泡也能分别拖动。轻点按钮仍执行切歌或暂停，拖动松手不会误触。双击页面空白处复位，窗口大小变化时也会复位以保持可见。轻点角色演示摸头；「仅看桌宠」隐藏预览说明，按 Esc 恢复。

此页仅使用示范曲目与原创示范歌词，不播放音频、不连接网易云、不请求大模型 API，也不更新已安装的桌宠。当前角色使用现有弹吉他动作的透明原始帧，保持原始帧时长。

2026-10-21：此布局已由用户确认，并以原生透明界面接入 0.8.1 后端。此前的独立播放器窗口方案未部署，已移除。此 HTML 仍作为使用示范数据的前端参考，不直接连接网易云；真实播放、歌词导入和同步功能在安装后的桌宠中。
